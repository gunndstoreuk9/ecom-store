> **The Tawazon Balance Matrix™** — 20 plant + mineral actives working on 3 levers the body uses to keep sugar steady:
> 1. **Slow the spike** after meals (White Mulberry, Bitter Melon).
> 2. **Help cells use sugar for energy** (Chromium, Alpha-Lipoic Acid, Cinnamon).
> 3. **Calm cravings** so good choices get easier (Gymnema, Cinnamon).
A **named mechanism** makes it feel proprietary and scientific — even though the actives are known. This is how you sell a $2 capsule for 299 MAD.

**Step 3 — Future pacing:** paint the 30/60/90-day life: steady energy, fewer cravings, calmer numbers, peace of mind, "back in control." (Compliant: lifestyle outcomes, not disease cure.)

### Order + line-item schema (Prisma sketch)

```prisma
model Order {
  id          String   @id @default(cuid())
  createdAt   DateTime @default(now())
  status      String   @default("new") // new | confirmed | shipped | delivered | returned
  name        String
  phone       String
  city        String
  address     String
  heroQty     Int      // 1 | 2 | 3
  heroPrice   Int      // 199 | 299 | 349

model OrderItem {
  id        String @id @default(cuid())
  orderId   String

  name      String
  price     Int    // always 199 for add-ons; hero price on hero row

}
```

- **Channel strategy (diversify — don't depend on Meta):**
  - **Advertorial bridge** before the offer (keeps Meta safe).
  - **TikTok** (Darija UGC, pharmacist/creator talking heads) — often the best ROI in Morocco.
  - **Google/YouTube** (high-intent: people search "تحاليل السكر", "طاقة", "حلويات") — search intent converts.
